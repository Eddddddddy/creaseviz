# 屏幕评估方法与边界

## 使用流程

1. 载入 ZAG，确认采集记录，再打开“屏幕评估”。STL 不参与这些计量指标。
2. 选择查看器当前数据或未修复的原始数据，选择完整记录或当前 XYZ 选区。
3. 确认扫描坐标中的转轴方向与位置。默认 X 为沿轴方向、Y 为跨轴方向，转轴暂按评估区域中线。
4. 选择分析间距、滤波尺度、基准和肩部范围，点击“开始评估”。
5. 可加入最多 8 条会话对比，或者下载带方法、范围、采集记录、单位和警告的 JSON / CSV。刷新不保留结果。

修改数据、选区或参数会使旧结果过期。不会在拖动选区时连续计算，也不会自动把旧数值标成当前结果。计算可取消，原始矩阵不会转移或改写。结果导出不需要网络。

## 数据、区域与空间尺度

ZAG 的 XY 间距和 Z 单位转换成真实毫米。掩码值 2 为缺测。X/Y 边界与源矩阵范围相交，再按内缩边距缩小；Z 为表面高度筛选而非数值钳制。Z 筛选改变统计人口，可能人为减小极值与 RMS，因此单独提示。

在矩形 X/Y 范围内建立等面积单元中心网格，双线性读取原始表面；不跨越缺测点插值。目标间距不得优于源分辨率，最多 600,000 格；必要时自动增大实际间距并报告。过窄选区及不能确定二维基准面的数据报错，不输出猜测。

默认形貌尺度为高斯 σ=0.25 mm，可选择不滤波、0.15、0.5、1、2 mm。先去除初始基准面的倾斜，对垂直残差进行归一化高斯卷积，再重建表面并重新拟合基准。卷积核截断为 ±3σ，边缘延拓；缺测中心保持缺测，归一化权重覆盖低于 99% 的位置不进入结果。整体翘曲另在法向残差上以默认 σ=5 mm 滤波。

80×30 mm 和 80×12 mm 快捷区域以扫描中心居中，长边沿指定转轴，保留当前 Z 范围。扫描中心不代表机械转轴定位，也不证明不同扫描已经配准。

## 面平整度

参考平面 `z=ax+by+c` 可采用最小二乘或六轮 Huber IRLS 稳健拟合。面高度采用到该平面的法向距离：

`r=(z−ax−by−c)/sqrt(1+a²+b²)`。

所有统计按有效分析单元等面积计权，不删除高低极值：

| 指标 | 定义与用途 |
| --- | --- |
| RMS / Sq 型 | `sqrt(mean(r²))`；整体偏离程度 |
| 平均绝对偏差 / Sa 型 | `mean(abs(r))` |
| PV / Sz 型 | `max(r)−min(r)`；对尖刺敏感 |
| F98 / F90 | P99−P1 / P95−P5；描述主体高度分布，不是删点 |
| Sp / Sv 型 | 正向最高峰 / 负向最深谷 |
| Ssk / Sku 型 | 相对基准的三阶 / 四阶归一化矩；零方差时为空 |
| Bow98 | 大尺度滤波残差的 P99−P1；描述整体翘曲 |

同时报告未形貌滤波的结果和中央区域结果。“未形貌滤波”仍指分析网格，不能解读为全分辨率逐像素统计；对极小尖刺敏感的 PV 可能受网格间距影响。页面额外列出源像素的真实原始 Z 极值（未去倾斜），需要局部极值时应缩小区域并减小分析间距。中央结果仍相对于完整评估范围拟合的同一参考面，不单独重新去除中央起伏。

以上是形貌统计定义，不是 ISO 25178 认证粗糙度评定链；PV 不是标准最小区域法平面度。稳健参考面改变的是参考，不是删除被识别为异常的高度。

## 中央折痕

默认中央为跨轴 ±6 mm，两侧肩部为离转轴 8–15 mm，沿轴按约 5 mm 分带。每条带先取跨轴中位截面，再做一维形貌滤波，双肩共同拟合参考直线；保留整体凹陷或隆起的符号。

- D：中央相对肩线的最大凹陷，向下为正。
- B：中央最大隆起，向上为正。
- 幅值：max(D,B)。
- S95：中央相对肩线的切线角差绝对值 P95。
- W50：中央最大绝对主峰的两个半高交点间距，使用线性插值。缺少任一交点时为空，不把选区宽度当作半高宽。
- A：两肩内缘之间的绝对截面积；对线性段跨零作分段积分，单位 µm·mm。

双肩与中央范围必须完整，肩部各侧至少三个分析位置且跨度不少于 0.5 mm，有效覆盖率至少 98%。不满足时只保留面指标，不外推折痕深度。汇总提供各带 P5/P50/P95；截面阴影是空间分布，不是置信区间。每个分带的数值可展开查看，JSON 保留全部分带及截面。

## 坡度和坡角

使用真实间距中央差分，只统计中心和四个邻点都有效的位置，不跨缺测孔洞求导：

- 方向角差：`atan(局部方向梯度)−atan(基准面方向梯度)`。
- 法向夹角：局部法向与基准法向的精确三维夹角，不用简单的梯度模近似替代。
- 梯度 RMS：`sqrt(mean((gx−a)²+(gy−b)²))`。
- 跨轴能量占比：跨轴梯度平方和 / 两方向梯度平方和；平面为无定义而非 0%。
- 角度绝对值报告 P50/P95/P99/P99.5/最大值、超过用户阈值的有效网格面积比例。
- 坡度百分比：`100*tan(angle)`。角差达到 90° 时不报告无意义的负坡度百分比。

全区和中央分别汇总。坡角不是手机开合角。可同时计算 σ=0.15 和 0.5 mm 的敏感性，不能把尺度差当成仪器测量不确定度。

## 对比与数据安全

不同机型、样本编号、静弯时间和恢复时间不自动配对。对比表检查尺寸、处理来源、滤波、基准、分辨率和 Z 截断情况；口径一致仍需人工确认物理对齐。不会输出合格分数或无来源排名。

CSV 对来源标签做公式注入防护；JSON 包含完整参数、范围、警告和来源信息。下载扫描派生文件不会把它们加入 Git。结果仅为几何分析，不推断视觉可见度、寿命、触感或光学反射表现。

## 可视化与验证设计

本地专门校核了以下层次，不另增图表依赖：

| 图层 | 数据与编码 | 校核 |
| --- | --- | --- |
| 面／角度热图 | 一个 Canvas2D 实例，最多 200×160 预览格；缺测灰色、残差蓝橙、角度顺序色；保留物理宽高比与坐标 | 数值独立于预览抽样，缩放重绘，HTML 标注与统计表作替代 |
| 跨轴截面 | React 管理的 SVG，毫米横轴、微米纵轴，中位数及分带 P5–P95 | 空值断线，阴影不冒充不确定度；响应容器宽度保持 11 px 标签 |
| 沿轴深度／隆起 | 同单位两条 SVG 曲线，无双轴或混合单位 | 数值表与 JSON 保留精确数据 |
| 面／坡角／比较表 | HTML 表格，单位、有效数量和处理来源可见 | 空值不是 0，方法不同时明确提示 |

前端页按需加载，所有矩阵计算放在可取消 Worker；无新 WebGL 场景，无网络服务或持久化。自动化覆盖倾斜平面、已知高斯折痕、精确法向夹角、缺测、Z 截断、XY 区域、资源预算和导出安全；私有原始扫描校验产物不进入公开仓库。
