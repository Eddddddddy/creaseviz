# 折痕扫描查看器

本地运行的折叠屏折痕三维查看器。支持：

- 直接导入 KEYENCE VR 系列 `.zag` 原始工程；
- 读取 ZAG 中的四次采集记录、逐像素 `int32` 高度矩阵、掩码、纹理、色带和 XY/Z 标定；
- 导入二进制或 ASCII STL；
- 三维旋转、平移、缩放和标准视角；
- 固定场景灯光、环绕视角和不限角度的模型旋转模式；
- 高度着色、原始纹理、素模及独立 X/Y/Z 显示比例；
- 无级截面曲线、可开关的三维截面位置平面和真实坐标读数；
- 多点真实高度标记、标签单点删除和一键清除全部标记。

## 运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址，然后拖入 `.zag` 或 `.stl` 文件。文件只在浏览器本地处理，不会上传。

## 数据解释

ZAG 高度使用工程内的 `MeterPerUnit` 转换为毫米，XY 使用 `MeterPerPixel` 转换。掩码值 `2` 作为无效点跳过。为了保持交互性能，三维显示会按规则网格下采样；原始像素数和显示点数会分别呈现。

STL 格式本身不记录单位和导出时的高度显示倍率。本项目样本的 `stl2.stl` Z 范围为 ZAG 第一组真实高度范围的 10 倍，因此精确测量以 ZAG 为准，STL 仅作为通用网格查看入口。

## 仓库范围

Git 只保存查看器源码、配置、设计资料和可复现分析脚本。原始 `.zag` / `.stl` 扫描、依赖目录、构建产物及扫描派生输出默认忽略，避免仓库体积膨胀和测量数据意外外泄。

当前 `pnpm build` 已通过。多点标记、模型/相机交互、截面位置与清除全部标记已经用真实 ZAG 验证；标签单点删除已完成实现和类型检查，仍建议在刷新后的浏览器中补一次人工点击确认。
