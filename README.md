# CreaseViz — 折痕扫描查看器

本地运行的折叠屏折痕三维查看器。支持：

- 直接导入 KEYENCE VR 系列 `.zag` 原始工程；
- 读取 ZAG 中的多条采集记录、逐像素 `int32` 高度矩阵、掩码、纹理、色带和 XY/Z 标定；
- 导入二进制或 ASCII STL；
- 三维旋转、平移、缩放和标准视角；
- 固定场景灯光、环绕视角和不限角度的模型旋转模式；
- 高度着色、原始纹理、素模及独立 X/Y/Z 显示比例；
- 无级截面曲线、可开关的三维截面位置平面和真实坐标读数；
- 多点真实高度标记、标签单点删除和一键清除全部标记；
- 可逆的局部去尖刺修复：可调真实高度阈值/邻域、原始对比、修复点统计，并同步用于 OBJ 与影视导出；
- 独立屏幕评估页：支持完整数据或 XYZ 选区，计算面平整度、中央折痕和真实坡角，可比较记录并下载 JSON / CSV；
- 将当前 ZAG 网格导出为 OBJ，可选择真实比例或当前 XYZ 显示比例并下载到本机；
- 按真实 X/Y/Z 毫米范围选择整屏中的局部区域，实时裁剪预览并导出选区 OBJ；
- 独立影视导出工作区，可设置相机、旋转轴/角度/速度、分辨率、帧率和画面元素；
- 浏览器本地录制 WebM（VP9/VP8 自动选择），停止后补写可索引时长并下载到本机。

## 运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址，然后拖入 `.zag` 或 `.stl` 文件。文件只在浏览器本地处理，不会上传。

项目固定使用 `/creaseviz/` 作为生产环境基础路径，以匹配同名 GitHub 仓库的 Pages 地址。本地开发服务器会在终端中显示可访问地址。

## GitHub Pages 部署

仓库已包含 `.github/workflows/deploy-pages.yml`。创建名为 `creaseviz` 的 GitHub 仓库并推送 `main` 分支后：

1. 打开仓库的 **Settings → Pages**；
2. 将 **Source** 设为 **GitHub Actions**；
3. 手动运行 `Deploy CreaseViz to GitHub Pages`，或再次向 `main` 推送提交。

部署后的默认地址为：

```text
https://<GitHub 用户名>.github.io/creaseviz/
```

工作流会依次安装依赖、运行测试、构建生产文件并部署 `dist`。扫描文件仍由用户在浏览器本地打开，不会被打包到站点或上传到 GitHub。

## 影视导出

载入模型后点击顶部的“影视导出”。导出页会沿用当前模型、材质、灯光和 XYZ 显示比例：

1. 通过鼠标或数值设置相机方位角、俯仰角、距离和观察中心；
2. 设置旋转轴、方向、起始角、总角度和速度，使用播放按钮预览；
3. 选择 720p、1080p、1440p、4K、竖屏、方形或自定义分辨率，并设置 24–60 FPS；
4. 点击“开始录制”，到达目标角度后自动停止，也可以随时手动停止；
5. 录制完成后点击“下载视频”。

录像使用浏览器原生画布视频流，只在本机内存中生成。第一版输出格式为 WebM；实际实时帧率取决于 GPU 和所选分辨率，高负载设置会在页面中提示。

## 数据解释

ZAG 高度使用工程内的 `MeterPerUnit` 转换为毫米，XY 使用 `MeterPerPixel` 转换。掩码值 `2` 作为无效点跳过。为了保持交互性能，三维显示会按规则网格下采样；原始像素数和显示点数会分别呈现。

大体积 ZAG 工程按 ZIP 目录随机读取，只解压当前采集记录需要的条目，切换记录不再重新读入整个工程。设备型号、序列号和保存的色带范围可缺省；高度矩阵、标定、掩码和实际读取条目的完整性仍严格校验。

STL 格式本身不记录单位和导出时的高度显示倍率，因此精确测量应优先使用带标定信息的 ZAG；STL 仅作为通用网格查看入口。

## 屏幕评估（ZAG）

界面默认只展示常用操作；查看器、区域选择、去尖刺、OBJ 导出、屏幕评估和影视导出的专业参数位于默认收起的“高级设置”。收起菜单不会重置或停用参数。去尖刺默认 20 µm / 0.3 mm / 仅向上，OBJ 默认真实比例 / 高精度，评估默认沿用已验证的 0.1 mm 分析间距、σ 0.25 mm 和最小二乘参考面，可直接开始；转轴方向仍需人工确认。自定义方法会明确提示，并可恢复推荐参数。评估恢复操作保留转轴方向、数据来源和选区，不会覆盖原始扫描。

顶部“屏幕评估”打开独立工作区。支持当前 XYZ 选区或完整采集记录，原始数据或查看器当前去尖刺结果。可配置转轴方向／位置、双侧肩部、中央范围、分带宽度、分析间距、形貌滤波尺度和最小二乘／稳健参考面；80×30、80×12 mm 快捷区域便于相同面积比较。

包含 RMS、平均绝对偏差、PV、F98/F90、峰谷与偏斜／峰度、Bow98；中央折痕深度、隆起、幅值、半高宽、截面积及分带 P5/P50/P95；跨轴／沿轴／法向坡角分布、坡度百分比、超阈值面积比、梯度 RMS 和方向能量比例。提供原始／形貌滤波后统计、可选滤波尺度敏感性、热图和截面曲线。

结果可加入最多 8 条会话对比，或下载带方法及范围的 JSON / CSV。选区或参数改变后，旧结果明确标为过期并要求重新计算；不自动保存或上传。缺测不填零，缺少两侧肩部时不外推折痕指标；Z 选区截断高度分布时会警告。显示倍率、相机和灯光不参与计算。

这些是几何形貌评估，不等同于标准最小区域法平面度或经过规定滤波链的认证粗糙度。完整定义和边界见 [评估方法说明](docs/assessment-methods.md)。

## 去尖刺（ZAG）

载入 ZAG 后，右侧“去尖刺”可以计算并应用孤立突跳修复。默认仅处理向上的尖刺，高度阈值 20 µm、邻域半径 0.3 mm；也可选择同时修复向下突跳。阈值越低越敏感；半径按 XY 标定换算成像素，限制为 1–64 像素，并显示实际使用的物理半径。参数修改后需重新计算，不会隐式叠加处理。

算法使用四组对称邻点的局部平面预测，要求四个方向同时超过高度阈值；仅修复不超过邻域直径的小连通区域，不进行全局平滑。长条折痕、大范围起伏、扫描边界和含缺测点的邻域受到保护。候选点超过整幅的 5% 或 100 万点时停止处理，提示调整参数。处理在可取消的 Worker 中完成，作用于当前整条采集记录而非仅选区。

“查看原始数据 / 应用修复结果”可反复对比，保持视角、显示比例、色标和选区；已有高度标记会清除，避免残留旧数值。修复后读数、截面、自动范围、选区 OBJ 和影视导出均使用同一份修复数据。修复 OBJ 文件名带 `despiked`，文件头注明参数与修复点数。切换采集记录或文件会清除本次修复；原始文件永不改写，关闭页面不保存修复。

该方法不能判断一个孤立小凸点究竟是灰尘、测量噪声还是真实屏幕缺陷；被修复的高度属于估计值，不是新测量值。请先用默认参数对照原始数据，不要用去尖刺代替缺陷判定或计量不确定度评估。

## OBJ 模型导出

加载 ZAG 后，可在右侧“模型导出”区域生成 OBJ。导出坐标单位为毫米，轴定义为 X=扫描横向、Y=扫描纵向、Z=测量高度：

- **真实比例**：以 1:1:1 输出，不应用查看器中的高度夸张；
- **当前显示比例**：应用界面当前的 X/Y/Z 显示比例，适合保留演示时的夸张造型。

OBJ 在浏览器 Worker 中从原始高度矩阵生成并直接下载，不会上传。支持预览（最多 20 万点）、高精度（最多 80 万点）和原始采样（小选区）三种精度；较小区域不降采样，导出结果会注明采样步长。保留 UV，不包含高度色材质或 ZAG 纹理图片；如需保持精确测量比例，应选择“真实比例”。

### 整屏区域选择

1. 打开 ZAG 并选择采集记录，开启右侧“区域选择”；
2. 用滑条或数值输入设置 X/Y 的屏幕平面范围和 Z 的测量高度范围，数值始终为原始毫米坐标，不受显示比例影响；
3. 模型实时显示蓝色选区框，范围外的表面隐藏；“中央区域”“恢复全范围”“聚焦选区”用于快速定位，关闭开关恢复整屏；
4. 在“模型导出”选择比例和精度，点击“下载选区 OBJ”。

深度着色中的“恢复自动范围”会在开启选区时，按当前 XYZ 选区内有效表面的真实最小/最大高度重算色标（包含边界插值，不受显示倍率影响）；关闭选区时恢复完整模型的默认自动范围。选区没有有效表面时会提示并保留原色标。调整选区后再次点击即可重算，不会在拖动时反复扫描原始矩阵。

跨越选区边界的三角面会被精确裁剪，并插值生成边缘顶点及 UV；范围外的顶点、无效采样点不写入 OBJ。选区仍是开放的屏幕表面，不会自动封底或生成实体厚度。选区中的原始采样若超过导出上限，请缩小范围或使用高精度自动采样。更换文件或采集记录会重置选区。

## 仓库范围

Git 只保存查看器源码、配置、设计资料和可复现分析脚本。原始 `.zag` / `.stl` 扫描、导出的 `.obj`、依赖目录、构建产物及扫描派生输出默认忽略，避免仓库体积膨胀和测量数据意外外泄。

提交或发布前运行 `pnpm check`。该命令会检查公开内容、代码规范、自动化测试和生产构建。
